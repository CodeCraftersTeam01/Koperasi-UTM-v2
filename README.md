# 🛒 Koperasi UTM v2

Website Profil & Sistem E-Commerce Koperasi Mahasiswa Universitas Trunojoyo Madura (UTM).

## 🚀 Tech Stack
- **Frontend**: React 19, Vite, Framer Motion, Recharts
- **Backend**: PHP Laravel Lumen 10, MySQL

## 📦 Fitur Utama
- **Katalog Produk & Kategori**: Manajemen produk, filter kategori, subkategori, dan tag promo/best seller.
- **Pengurus & Organisasi**: Struktur kepengurusan koperasi bertingkat dengan foto profil.
- **Galeri & Layanan**: Dokumentasi kegiatan dan daftar layanan koperasi.
- **Checkout & Notifikasi**: Pemesanan via WhatsApp terintegrasi nota unik dan pencatatan pesanan masuk.
- **Optimasi Upload Gambar**: Kompresi otomatis di sisi client (canvas) dan validasi file multi-format.
- **Panel Admin**: Manajemen konten lengkap dan aman berbasis API token.
